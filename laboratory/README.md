# Teaching laboratory

Run `python3 memory_lab.py` from this directory. The file contains the fixture and its deterministic tests. It creates temporary synthetic SQLite databases and uses no model API or application history.

The dated verification files preserve the historical checks described in Appendix B. The PostgreSQL files are design sketches: the gateway example is read-only and the write protocol remains an unexecuted integration proposal. They are not a production backend or a full harm/shutdown controller.
