# Persona: upcoming versions

Proposed direction as of October 15, 2026. The features below are planned, with no release dates assigned.

## 0.6 | Richer event understanding

Planned: represent several actions and their actors separately within one message; improve attribution when quoting, admitting a mistake or supporting someone else; make the cause of a reaction easier to inspect. The aim is a character that reacts to each person's actual role in an event.

## 0.7 | Longer shared history

Planned: consolidate related episodes without losing their sources, improve recall across English and Portuguese, add streamed replies and make profile recovery independent of a single browser cookie.

## Memory infrastructure research

Compare original-source recall with existing memory under the same tasks and budget; evaluate temporal corrections, model migration and a portable history format. Full bitemporal queries and REST/MCP memory adapters remain future work. No release date is assigned.
