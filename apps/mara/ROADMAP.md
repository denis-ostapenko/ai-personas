## 0.4 · More control over memory

Planned: a clear correction and selective-forgetting flow, stronger contradiction handling, easier inspection of the reasons a memory was retrieved, and incremental indexing for larger histories.

## 0.5 · A smoother conversation

Planned: streaming replies, a Brazilian Portuguese interface, improved pending-action follow-up and broader development scenarios covering more than practical planning habits.

## Further directions

Investigate development of interests and dispositions, calibrated task-specific habit retirement, and model migration with continuity checks. Hosting, authenticated multi-user operation and voice require separate product and runtime work.

These are development directions, with no assigned release dates. Current functionality is documented in [release notes](CHANGELOG.md).

## Memory infrastructure research

Compare original-source recall with existing memory under the same tasks and budget; evaluate temporal corrections, model migration and a portable history format. Full bitemporal queries and REST/MCP memory adapters remain future work. No release date is assigned.
