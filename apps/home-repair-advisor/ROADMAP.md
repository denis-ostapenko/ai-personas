# Home Repair Advisor: upcoming versions

Proposed direction as of October 15, 2026. The features below are planned, with no release dates assigned.

## 0.5 | More useful local comparisons

Planned: improve matching between business websites and review profiles, recover more relevant price evidence and explain differences between comparable offers. Add a saved-case browser so a customer can return to earlier work.

## 0.6 | Smoother bilingual workflow

Planned: localize the interface and application-generated report labels into Brazilian Portuguese, add easier case recovery and prepare a compact bilingual job summary for sharing with a chosen provider.

## Memory infrastructure research

Compare original-source recall with existing memory under the same tasks and budget; evaluate temporal corrections, model migration and a portable history format. Full bitemporal queries and REST/MCP memory adapters remain future work. No release date is assigned.
