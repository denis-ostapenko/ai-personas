# Development history

Denis Ostapenko directs the project. Implementation and review used Codex and Claude, supported by the project's research library. Research organization began on September 13, 2026 around three tracks: self-evolving personalities, human digital replicas and authored personalities. The two applications in this repository belong to the authored track.

## Home Repair Advisor

| Date | Version | Development |
|---|---|---|
| 2026-10-11 | 0.1 | Photo and text assessment, ZIP lookup, web evidence, saved cases and browser UI. |
| 2026-10-11 | 0.2 | Numeric budgets, business review profiles and an optional Google Places adapter. |
| 2026-10-12 | 0.3.0 | Quoted facts, a correction journal, job epochs and identity continuity. |
| 2026-10-14 | 0.3.1 | Environment-based startup, complete snapshots and standalone packaging. |
| 2026-10-14 | 0.3.2 | English and Brazilian Portuguese conversation rules, compatible case migration, bilingual release copy and MIT licensing. |

The architecture separates job assessment, source extraction and budget calculation. Models interpret the request and extract evidence; application code validates quotations, maintains the case and calculates estimates. The character is expressed through a consistent professional role and manner.

## Persona

| Date | Version | Development |
|---|---|---|
| 2026-10-12 | 0.1.0 / 0.1.1 | Local conversation, onboarding, character controls, memory, then selective editing and deletion. |
| 2026-10-13 | 0.2.0 | Separate identity, memory and conversation layers; contextual appraisal and linked memories. |
| 2026-10-13 | 0.3.0 | SQLite storage, reaction cells, correction history and continued memory capture after forgetting. |
| 2026-10-13 | 0.4.0 | Authored temperament, six controls, mood, relationship state and event replay. |
| 2026-10-14 | 0.4.1 | Actor-specific relationship changes, separate interpersonal friction and complete snapshots. |
| 2026-10-14 | 0.4.2 | Explicit bilingual conversation rules, compatible chat upgrades, English internal topic titles, bilingual release copy and MIT licensing. |

The architecture separates enduring identity from memory and current state. A model describes an event; code computes the reaction; dialogue expresses it in the character's voice. The 0.4.1 attribution repair prevents unrelated third-party emotion from directly becoming conflict with the user. Several actors in one message remain a focus for the next iteration.
